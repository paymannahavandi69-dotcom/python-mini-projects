Python Portfolio Projects

Welcome to my Python portfolio. This repository contains four practical, command-line applications built with Python. Each project demonstrates core programming concepts, clean code structure, and real-world problem-solving. The projects are designed to showcase my ability to build functional, maintainable, and user-friendly software.
1. Calculator
Description

A professional command-line calculator that performs basic arithmetic operations with robust error handling. The application supports continuous calculations, maintains a transaction history, and allows users to save results to a file for future reference.
Features

    Addition, subtraction, multiplication, and division of two numbers

    Division-by-zero protection with clear error messages

    Input validation for non-numeric entries

    Persistent calculation history stored in a list

    Option to save history to a text file

    Interactive menu loop with quit functionality

Technologies Used

    Python 3

    Object-Oriented Programming (Classes, __init__, __str__, __len__)

    Exception Handling (try/except, raise)

    File I/O operations

    f-strings for formatted output

2. Todo List
Description

A task management application that allows users to create, view, complete, and delete tasks. The application persists tasks to a file, enabling users to resume their work across sessions. It is designed with a clean object-oriented architecture and includes error handling for invalid inputs.
Features

    Add new tasks with a title

    Display all tasks with completion status (✓ / ✗)

    Mark tasks as completed

    Remove tasks by index

    Save tasks to a file and load them back

    Input validation and error handling

    Interactive menu loop

Technologies Used

    Python 3

    Object-Oriented Programming (Classes, __init__, __str__, __len__)

    Lists and dictionaries for data storage

    File I/O operations

    Exception Handling (try/except)

    f-strings for formatted output

3. Contact Manager
Description

A contact management system that stores names, phone numbers, and email addresses. Users can add, search, list, and delete contacts. The application supports persistent storage via file I/O, making it suitable for personal or small-business use.
Features

    Display all contacts in a numbered list

    Search contacts by name (case-insensitive)

    Remove contacts by index

    Save contacts to a file and load them back

    Input validation and error handling

Technologies Used

    Lists for data storage

    File I/O operations

    Exception Handling (try/except)

    f-strings for formatted output

4. Bank System
Description

A complete banking system that simulates real-world account management. It includes a base Account class and two derived classes: SavingsAccount and CheckingAccount. The system supports deposits, withdrawals, interest calculation, overdraft protection, transaction history, and file-based persistence.
Features

    Base Account class with owner name and balance

    SavingsAccount with interest calculation

    CheckingAccount with overdraft limit

    Deposit and withdrawal methods with validation

    Clear error messages for insufficient funds and invalid amounts

    Transaction history stored in a list

    Save history to a file

    Interactive menu loop with account selection

    Inheritance and super() usage

    isinstance() for account type checking

Technologies Used

    Python 3

    Object-Oriented Programming (Inheritance, super(), __init__, __str__)

    Exception Handling (try/except, raise)

    File I/O operations

    Lists for transaction history

    f-strings for formatted output
